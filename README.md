# 周末半径 Weekend Radius

面向广州个人用户的周末活动智能规划微信小程序原型。

当前版本已经进入 Phase 2：支持用户真实定位，通过百度地图地点检索获取评分、评论数、价格和营业时间，并保留腾讯位置服务作为降级数据源与导航支撑。

## 当前已实现

- 设置周六或周日、全天精确到分钟的时间、预算、兴趣、Mood、距离和避雷项
- 通过 0–500 元预算滑块快速选择，或输入最高 99999999 元的自定义预算
- 从 23 类活动兴趣中选择，或添加自己的活动类型
- 通过独立规则模块推荐 3–5 个广州活动
- 展示可解释的推荐分、评分构成和推荐理由
- 将百度地图评分、评论数与报告价格纳入推荐排序，并对评论样本过少的高分做信心度收缩
- 选择一个活动作为 Anchor Event
- 围绕 Anchor Event 生成带时间、交通和预算的一日计划
- 只替换一个普通节点，或跳过该节点
- 自动识别节点之间的空档，并推荐时间、路线和预算都放得下的新活动
- 保持 Anchor Event 和其他节点不变
- 在本地保存计划并再次打开
- 自动区分待出发、进行中和已完成计划，并支持确认后删除
- 获取用户当前定位，或允许用户在地图上手动选择广州出发点
- 按真实出发点重新计算活动预计交通时间
- 通过云函数搜索 Anchor Event 周边真实餐厅、咖啡馆、甜品店、公园、商场与城市去处
- 通过腾讯位置服务核对广东省博物馆、广州艺术博物院、广东美术馆、南越王博物院、广州图书馆和广州市文化馆等真实场馆
- 真实场馆使用完整地址和地图坐标，可从活动详情与行程节点直接打开微信地图
- 没有真实坐标的演示活动明确显示“演示活动”，并禁用导航，避免概念地址被误认为可到达地址
- 场馆参观使用“建议时段”，不伪装成有固定开场时间的限时活动
- 实时接口不可用时自动降级到本地演示地点
- 在行程节点中明确区分“实时地点”与演示数据，并标注费用、营业时间的估算边界

## 项目结构

```text
weekend-radius/
├─ project.config.json          微信开发者工具项目配置
├─ tsconfig.json                TypeScript 配置
├─ miniprogram/
│  ├─ pages/                    6 个正式页面
│  ├─ components/               可复用 UI 组件
│  ├─ types/                    核心数据结构
│  ├─ data/                     广州活动、地点与选项演示数据
│  ├─ recommendation/           活动筛选和可解释评分
│  ├─ itinerary/                行程生成、局部替换与跳过逻辑
│  ├─ services/                 本地存储
│  │                            定位、实时地点搜索与数据降级
│  ├─ utilities/                时间、距离和交通估算
│  └─ assets/                   本地视觉素材
└─ cloudfunctions/
   └─ searchPlaces/             腾讯位置服务周边 POI 搜索云函数
```

页面代码只负责收集选择和展示结果。推荐、行程生成和 Replace 逻辑没有写进页面点击事件中。

## 如何在微信开发者工具中打开

1. 打开微信开发者工具。
2. 在首页选择“小程序”。
3. 点击“导入项目”或右上角的“+”。
4. 项目目录选择本文件所在的 `weekend-radius` 文件夹，不要只选择里面的 `miniprogram` 文件夹。
5. 项目名称填写“周末半径”。
6. AppID 使用项目内置的测试号配置；如果工具要求选择 AppID，选择“测试号”即可。
7. 点击“导入”。

正常情况下，编译完成后模拟器会显示暖色的广州首页，标题为“这周末想怎么玩？”。

## 第一轮验收路径

建议先使用默认偏好测试：

- 周六
- 11:00–21:00（小时与分钟使用独立滚轮选择）
- 预算 200 元
- 艺术、咖啡、美食
- Explore
- 30 分钟以内

然后依次检查：

1. 点击“开始规划”。
2. 点击“看看适合我的活动”。
3. 推荐页出现广州活动卡片和 Match Score。
4. 打开“城市切片：当代影像展”。
5. 点击“围绕这个活动安排一天”。
6. 时间线中出现不能替换的 Anchor Event。
7. 对普通节点点击“换一个”，选择候选项。
8. 确认只有当前节点变化。
9. 点击“保存这份计划”。
10. 返回首页，从“上次的周末”再次打开计划。

## 当前边界

- 云服务未配置时 Anchor Event 仍会使用明确标记的演示活动；配置后优先展示已核对的真实场馆参观
- 真实场馆不等于实时限时活动：真实展览、演出和市集档期将在 Phase 3 从官方排期源接入
- 百度地图地点检索可提供部分 POI 的评分、评论数、价格和营业时间；字段缺失时仍会明确标注为估算
- 直线距离已按真实坐标计算，公交和步行时间仍是规则估算，尚未接路线规划 API
- 实时 POI 需要先开通微信云开发环境并配置腾讯位置服务 Key
- 未接入微信登录、云数据库或模型 API
- 当前目标是让真实数据逐层替换演示数据，同时保持 Golden Path 稳定可用

## 启用腾讯实时地点

1. 在微信开发者工具顶部点击“云开发”，创建一个开发环境并记下环境 ID。
2. 在腾讯位置服务控制台创建应用和 Key，启用 WebService API，并绑定本项目的小程序 AppID。
3. 将 `cloudfunctions/searchPlaces` 上传并部署到刚创建的云环境。
4. 在云函数配置中添加环境变量 `TENCENT_MAP_KEY`，值为腾讯位置服务 Key。不要把 Key 写进小程序前端代码或提交到公开仓库。
5. 把云环境 ID 填入 `miniprogram/config/runtime.ts` 的 `CLOUD_ENV_ID`，重新编译。

配置成功后，选择 Anchor Event 时会显示“搜索附近地点…”，生成的真实地点节点带有“实时地点”标记。
